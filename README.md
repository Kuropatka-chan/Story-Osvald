# Story-Osvald

Мини-визуальная новелла на основе файла «Окончательное решение демонического вопроса.txt».

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер в корне репозитория:

```bash
python -m http.server 8000
# затем откройте http://localhost:8000
```

Управление: пробел/клик — следующий кадр, стрелки влево/вправо или кнопки «Назад/Вперёд» для навигации.

## Структура
- `index.html` — точка входа и UI.
- `main.js` — простой движок (смена сцен, обработка ввода).
- `assets.js` — пути к текстурам по названиям из сценария.
- `storyData.js` — главы и реплики.
- `ROADMAP.md` — шпаргалка по файлам и шагам расширения.
